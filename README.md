# TANDA.com на Django

Аренда легковых машин и бусиков с водителем напрямую от владельцев по Кыргызстану.
Прототип команды TANDA для хакатона Enactus, Salymbekov University.

**Что умеет сайт**

- Каталог с фильтрами по городу, датам и типу транспорта. Машины, занятые на выбранные даты, скрываются.
- Регистрация и вход по номеру телефона и паролю, профиль, смена пароля, удаление аккаунта.
- «Сдать машину»: объявление с фото, проверка ОСАГО, калькулятор заработка владельца.
- Бронирование: расчёт цены с комиссией и сбором, фото прав (видят только владелец и TANDA), номер заявки `T-XXXXX`.
- Личный кабинет: заявки на мои машины (подтвердить или отклонить), мои поездки, мои объявления.
- После подтверждения брони стороны видят телефоны друг друга.
- ИИ на Claude: помощник подбирает машину под поездку, подсказывает владельцу цену и описание, сравнивает фото при выдаче и возврате и отмечает новые повреждения.
- Админка Django: все объявления, брони и пользователи.

Стек: Python 3.10+, Django 5.2, SQLite, Pillow, Anthropic Python SDK. Фронтенд без сборки: шаблоны Django, CSS и чистый JavaScript.

## Быстрый старт

Нужен Python 3.10 или новее (`python --version`).

**Windows (PowerShell или cmd)**

```bat
cd tanda_django
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python manage.py migrate
python manage.py seed_demo
python manage.py createsuperuser
python manage.py runserver
```

**macOS и Linux**

```bash
cd tanda_django
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python manage.py migrate
python manage.py seed_demo
python manage.py createsuperuser
python manage.py runserver
```

Откройте http://127.0.0.1:8000. Админка: http://127.0.0.1:8000/admin/

- `seed_demo` добавляет 11 демо-объявлений с фотографиями реальных моделей (8 легковых машин и 3 бусика). Демо-фото лицензированы, авторы и источники перечислены в `rentals/static/rentals/img/README.txt`. Убрать объявления: `python manage.py seed_demo --remove`.
- `createsuperuser` создаёт администратора. Логин можно указать любой, например `admin`. Он входит и в админку, и на сайт через обычную форму входа.

## Как включить ИИ

1. Получите ключ на https://console.anthropic.com (раздел API Keys).
2. Впишите его в файл `.env`: `ANTHROPIC_API_KEY=sk-ant-...`
3. Перезапустите сервер.

Модель задаётся в `.env` строкой `ANTHROPIC_MODEL` (по умолчанию `claude-sonnet-5-5`). Без ключа сайт работает полностью, только помощник, подсказка цены и осмотр по фото вежливо сообщают, что ИИ не подключён.

Каждый запрос к ИИ платный, поэтому на сайте стоит ограничение: не больше 30 сообщений помощнику, 15 подсказок цены и 10 осмотров за 10 минут с одного аккаунта или IP. Числа меняются в `rentals/api.py`.

## Проверка за 5 минут (сценарий для демо)

1. Зарегистрируйтесь на сайте как арендатор (кнопка «Войти» → «Зарегистрироваться»).
2. Откройте любую демо-машину, выберите даты, загрузите любое фото как права и отправьте заявку.
3. Войдите под администратором: заявки на демо-машины приходят ему в «Кабинет». Подтвердите заявку.
4. Снова войдите как арендатор: бронь подтверждена, виден телефон владельца, машина пропала из каталога на эти даты.
5. «Сдать машину»: заполните форму, нажмите «Подсказать цену и описание», опубликуйте.
6. «Осмотр по фото»: сфотографируйте машину дважды с одного ракурса, перед вторым снимком приклейте на дверь полоску малярного скотча.

Чтобы бронировать свою же машину, нужен второй аккаунт: себе забронировать нельзя.

## Где что лежит

```
tanda_django/
├── manage.py
├── requirements.txt
├── .env.example            образец настроек (скопировать в .env)
├── tanda/                  настройки проекта и главный urls.py
└── rentals/                всё приложение TANDA
    ├── rules.py            комиссии, сбор, депозит, города, расчёт цены
    ├── models.py           Profile, Listing (объявление), Booking (бронь)
    ├── forms.py            регистрация, вход, профиль, объявление, бронь
    ├── views.py            страницы сайта
    ├── api.py              JSON для ИИ: /api/assistant/, /api/suggest-price/, /api/inspect/
    ├── ai.py               запросы к Claude и тексты промптов
    ├── images.py           уменьшение фото с телефона
    ├── admin.py            админка
    ├── tests.py            тесты
    ├── management/commands/seed_demo.py   демо-каталог
    ├── templates/rentals/  HTML-шаблоны
    └── static/rentals/     tanda.css, tanda.js, картинки
```

**Частые правки**

- Комиссия 20% и 15%, сбор 5%, депозит 5 000 сом: `rentals/rules.py`.
- Список городов: `CITIES` в `rentals/rules.py`.
- Контакты в подвале: `TANDA_CONTACT` в `tanda/settings.py`.
- Фото на главном экране: положите `hero.jpg` в `rentals/static/rentals/img/` и перезапустите сервер.
- Фото демо-машин хранятся в `rentals/static/rentals/img/demo/` и копируются в `media/` командой `python manage.py seed_demo`.
- Текст и правила помощника: функция `assistant_system` в `rentals/ai.py`.

После изменения `models.py` выполните `python manage.py makemigrations` и `python manage.py migrate`.

## Тесты

```bash
python manage.py test
```

29 тестов проверяют расчёт цены, регистрацию и вход по телефону, объявления, бронирование и занятость дат, доступ к фото прав, роль администратора для демо-машин и ИИ-адреса (с подменой ответа Claude, без настоящего ключа).

## Данные и приватность

- База: файл `db.sqlite3` рядом с `manage.py`.
- Фото машин: папка `media/` (публичные).
- Фото прав: папка `private_media/`. Ссылки на неё нет, файл отдаётся только арендатору, владельцу машины и администратору. При удалении брони или аккаунта файл удаляется.
- Телефон видят владелец аккаунта и администратор TANDA, а после подтверждения брони — вторая сторона сделки.

## Запуск на сервере

### Render

В корне репозитория подготовлен `render.yaml` — Blueprint создаёт веб-сервис, PostgreSQL и постоянный диск для загруженных фото (включая приватные фото водительских прав).

1. Загрузите проект в GitHub и в Render выберите **New → Blueprint**, подключите репозиторий и нажмите **Apply**.
2. Сервис, диск и PostgreSQL должны быть в одном регионе. В Blueprint используется Сингапур; веб-сервис и постоянный диск платные. В Render можно заменить тариф Postgres на доступный в вашем аккаунте.
3. При создании Blueprint задайте `ANTHROPIC_API_KEY` из https://console.anthropic.com, если нужен ИИ. Секреты в репозиторий добавлять не нужно.
4. При запуске Render применит миграции и безопасно добавит демо-объявления. Создайте администратора через **Shell** веб-сервиса: `python manage.py createsuperuser`.
5. После деплоя откройте выданный Render URL. При добавлении собственного домена задайте его в переменных `ALLOWED_HOSTS` и `CSRF_TRUSTED_ORIGINS` веб-сервиса.

Статика раздаётся через WhiteNoise; PostgreSQL подключается через `DATABASE_URL`. Публичные фото объявлений доступны из `MEDIA_ROOT` на постоянном диске `/var/data`; закрытые фото прав лежат отдельно в `PRIVATE_MEDIA_ROOT` и не публикуются. Локальная SQLite-база, пользователи и пользовательские фото автоматически в Render не переносятся.

Для самостоятельного сервера используйте `DEBUG=0`, уникальный `SECRET_KEY`, `ALLOWED_HOSTS` и `CSRF_TRUSTED_ORIGINS` с вашим доменом, HTTPS, PostgreSQL и постоянное защищённое хранилище для `MEDIA_ROOT` и `PRIVATE_MEDIA_ROOT`. Не публикуйте `private_media/` напрямую. Статика собирается командой `python manage.py collectstatic --no-input`; приложение запускается через Gunicorn.

Для быстрого показа на хакатоне хватит `DEBUG=1` и `python manage.py runserver 0.0.0.0:8000`. Чтобы открыть сайт с телефона в той же Wi-Fi сети, добавьте IP компьютера в `ALLOWED_HOSTS`.

## Как залить в GitHub

Файлы `.env`, `db.sqlite3`, `media/` и `private_media/` уже в `.gitignore`, они не попадут в репозиторий.

```bash
git init
git add .
git commit -m "TANDA на Django"
git branch -M django
git remote add origin https://github.com/Amanek1011/Tanda.com.git
git push -u origin django
```

Код уйдёт в отдельную ветку `django` и не затронет то, что уже лежит в `main`.
